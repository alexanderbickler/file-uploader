File Uploader

A private document library that runs on your own PC. Upload files, see their name, date, size and type, and organise them into real folders.

View on GitHub Quick start

What you get

Upload anything

Click Upload or drag files onto the page. Progress is shown; duplicates are never overwritten.

See what matters

Document name, upload date, file size and file type in a sortable table, with search across every folder.

Real folders

Create, rename and move folders in the app and the same change happens on your disk — a normal, backup-friendly structure.

Local database

A SQLite index makes browsing instant. Rescan picks up files you add in Explorer.

Works on your phone

Responsive layout turns the table into cards and the folder tree into a drawer. Optional same-Wi-Fi mode.

Your look

One theme file controls every colour and font, so it can match your corporate style set.

Quick start

You need Node.js 22.5 or newer. There is nothing to install.

git clone https://github.com/alexanderbickler/file-uploader.git
cd file-uploader
npm start

Open http://localhost:3000. On Windows you can double-click start.bat instead. Documents are stored in the library/ folder next to the app.

Please note

There is no login. The app listens on your PC only by default. If you enable LAN mode for phone access, anyone on that network can read, upload and delete files — use it only on a trusted network. Deleting a document removes it from disk (no Recycle Bin). See the security notes.
